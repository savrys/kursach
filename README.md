# kursach
# Рыболовная база «Туманное утро»

Вебприложение для бронирования мест на рыболовной базе отдыха.

# Функционал

~Интерактивная карта с цветовой индикацией статусов мест
~Онлайнбронирование с выбором даты, времени и длительности
~Три роли пользователей: Посетитель, Управляющий, Администратор
~Подтверждение и отклонение заявок управляющим
~Таймер обратного отсчёта для активных броней
~Учёт улова и формирование топов рыбаков
~Встроенный чат для связи с администрацией
~Загрузка своей карты местности и фото мест
~Аудит действий и автоматический бекап базы данных

# Технологии

Сервер: Node.js, Express
Клиент: React, Vite
База данных: PostgreSQL
Документация API: Swagger

# Установка и запуск

1. Установить Node.js и PostgreSQL
2. Создать базу данных `fishing_base`
3. Установить зависимости: `npm install` в папках `server` и `client`
4. Запустить сервер: `npm start` (папка `server`, порт 5000)
5. Запустить клиент: `npm run dev` (папка `client`, порт 3000)
